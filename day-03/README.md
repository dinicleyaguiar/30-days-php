# Dia 03 — Day 03: Condicionais em PHP

Trilha: PHP  
Nível: iniciante  
Tema: Condicionais if, elseif e switch

## Objetivo

Praticar estruturas condicionais if/elseif/else e switch com exemplos práticos.

## Conceito

Implemente dois scripts que demonstrem o uso de condicionais. O primeiro verificará se um número é positivo, negativo ou zero. O segundo usará switch para processar opções de um menu simples.

## Desafio

Crie um script que receba um número via entrada padrão e exiba sua classificação. Depois, desenvolva outro que ofereça um menu com três opções e execute a ação correspondente.

## Pontos principais

- Estrutura if/elseif/else para tomada de decisão
- Uso de switch para seleção de opções
- Entrada de dados via PHP
- Controle de fluxo em situações distintas
