# Dia 10 — Day 10: Formulário com validação e cálculo

Trilha: PHP  
Nível: iniciante  
Tema: Revisão prática do nível iniciante

## Objetivo

Criar um formulário que coleta dados do usuário, valida entradas e exibe resultados formatados com cálculos e datas.

## Conceito

Este exercício combina manipulação de formulários, validação de dados, cálculos matemáticos, formatação de datas e exibição de resultados. O usuário deve implementar lógica para garantir que os dados sejam válidos antes de processá-los.

## Desafio

Implemente um formulário que: 1) Coleta nome, preço e quantidade de um produto 2) Valida que os valores sejam numéricos 3) Calcula total com desconto (10% se quantidade > 10) 4) Exibe data atual formatada no resultado

## Pontos principais

- Validação de entradas via PHP
- Cálculo de desconto condicional
- Formatação de datas com date()
- Exibição de resultados em HTML
