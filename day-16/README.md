# Dia 16 — Manipulação de JSON em PHP

Trilha: PHP  
Nível: intermediário  
Tema: JSON em PHP

## Objetivo

Praticar a conversão entre arrays PHP e formatos JSON, incluindo leitura e escrita de arquivos JSON.

## Conceito

Crie dois arquivos: um para converter dados PHP para JSON e outro para ler um arquivo JSON existente. Demonstre como serializar e desserializar dados usando funções nativas do PHP.

## Desafio

Implemente a leitura de um arquivo JSON externo e exiba seus dados em uma página HTML.

## Pontos principais

- Uso de json_encode() e json_decode()
- Manipulação de arquivos com fopen() e file_get_contents()
- Trabalho com arrays associativos
