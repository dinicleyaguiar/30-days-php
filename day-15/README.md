# Dia 15 — Day 15: Tratamento de exceções

Trilha: PHP  
Nível: intermediário  
Tema: Tratamento de exceções

## Objetivo

Implementar validação de entrada com tratamento de exceções para evitar erros de divisão por zero

## Conceito

Crie um script que receba dois números via GET, realize uma divisão e trate erros usando exceptions. Utilize um arquivo JSON para armazenar mensagens de erro.

## Desafio

Implemente um sistema que capture exceções quando o divisor for zero e exiba mensagens personalizadas usando um arquivo de configuração.

## Pontos principais

- Uso de try/catch para capturar exceções
- Criação de classes personalizadas para erros
- Armazenamento de mensagens de erro em arquivo JSON
