# Dia 29 — Day 29: Testes automatizados básicos

Trilha: PHP  
Nível: avançado  
Tema: Testes automatizados básicos

## Objetivo

Implementar testes unitários para validar funcionalidades de um sistema de login

## Conceito

Crie um sistema de login com validação de senha e implemente testes automatizados para verificar se as regras de segurança estão funcionando corretamente.

## Desafio

Desenvolva um script que valide senhas com regras específicas e escreva testes para verificar se as regras estão sendo aplicadas corretamente.

## Pontos principais

- Padrões de validação de dados
- Testes unitários básicos
- Uso de assert para verificação de resultados
