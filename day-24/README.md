# Dia 24 — Traits e namespaces: Sistema de veículos

Trilha: PHP  
Nível: avançado  
Tema: Traits e namespaces

## Objetivo

Implementar um sistema de veículos usando traits para reutilizar funcionalidades e namespaces para organizar classes.

## Conceito

Crie um sistema com classes para Carro e Moto que compartilhem métodos de aceleração e freio usando um trait. Organize as classes em namespaces separados para motor e utilitários.

## Desafio

Implemente um trait com métodos de aceleração e freio, crie duas classes em namespaces diferentes e demonstre o uso com objetos.

## Pontos principais

- Reutilização de código com traits
- Organização de código com namespaces
- Integração de traits em classes
