# Dia 09 — Formulários GET e POST

Trilha: PHP  
Nível: iniciante  
Tema: Formulários GET e POST

## Objetivo

Aprender a enviar e processar dados com métodos GET e POST em PHP

## Conceito

Crie um formulário que envie dados usando os métodos GET e POST. Mostre como recuperar os valores em páginas separadas. Inclua exemplos de exibição de dados e validação básica.

## Desafio

Implemente um sistema que permita ao usuário inserir um nome e exibir o resultado usando ambos os métodos de envio.

## Pontos principais

- Diferença entre GET e POST
- Como enviar dados via formulário
- Como recuperar dados em PHP
- Validação básica de entrada

- PHP lint OK: index.php
- PHP lint OK: process_get.php
- PHP lint OK: process_post.php
