# Dia 07 — Day 07: Manipulação de Strings

Trilha: PHP  
Nível: iniciante  
Tema: Strings e funções de texto

## Objetivo

Praticar funções de texto em PHP para formatar e analisar strings

## Conceito

Implemente um script que receba uma string e retorne: 1) comprimento da string, 2) posição do primeiro espaço, 3) substring até o espaço, 4) versão minúscula e 5) versão maiúscula. Teste com a string 'PHP é divertido para aprender'.

## Desafio

Crie uma função que processe strings e retorne os valores solicitados

## Pontos principais

- Uso de funções como strlen(), strpos(), substr(), strtolower() e strtoupper()
- Manipulação de strings para extração de partes específicas
- Tratamento de strings para normalização de dados
