# Dia 01 — Day 01: Introdução a variáveis e tipos de dados

Trilha: PHP  
Nível: iniciante  
Tema: Variáveis e tipos de dados

## Objetivo

Praticar a declaração de variáveis e identificação de tipos de dados básicos em PHP

## Conceito

Crie um script que declare variáveis com diferentes tipos (inteiro, string, booleano, float) e exiba seus tipos. Use funções nativas para verificar os tipos e mostre como PHP trata conversões implícitas.

## Desafio

Implemente um sistema que receba um valor e determine automaticamente seu tipo, mesmo que haja conversão implícita.

## Pontos principais

- Declaração de variáveis sem tipo definido
- Tipos básicos: integer, string, boolean, float
- Uso de funções como gettype() e var_dump()
- Comportamento de conversão implícita em PHP
