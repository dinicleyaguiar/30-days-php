# Dia 20 — Day 20: Sistema de Posts Simples

Trilha: PHP  
Nível: intermediário  
Tema: Mini projeto intermediário

## Objetivo

Criar um sistema básico de cadastro de posts usando formulário, validação e armazenamento em arquivo JSON.

## Conceito

Este exercício combina formulário com validação, manipulação de strings e escrita em arquivo JSON. O sistema permite adicionar novos posts com título e conteúdo, salvando-os em um arquivo para persistência.

## Desafio

Implementar a validação de campos obrigatórios e garantir que os dados sejam salvos corretamente no formato JSON.

## Pontos principais

- Manipulação de formulários com POST
- Validação de entrada de usuário
- Escrita e leitura de arquivos JSON
- Estrutura de dados para armazenamento de dados
