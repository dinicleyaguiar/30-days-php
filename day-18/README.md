# Dia 18 — Conexão PDO e operações básicas com banco

Trilha: PHP  
Nível: intermediário  
Tema: PDO e conexão com banco

## Objetivo

Implementar conexão com banco de dados usando PDO, inserir e consultar dados

## Conceito

Crie um sistema simples que conecte-se a um banco MySQL, insira dados via formulário e exiba registros. Use prepared statements para segurança e trate erros com try/catch.

## Desafio

Implemente a lógica de conexão, inserção e consulta em arquivos separados. Garanta que o código funcione com um banco configurado previamente.

## Pontos principais

- Conexão PDO com MySQL
- Prepared statements para prevenção de SQL injection
- Manipulação de erros com try/catch
- Integração com formulários HTML
