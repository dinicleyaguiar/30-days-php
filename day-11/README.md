# Dia 11 — Day 11: Organização de arquivos com includes

Trilha: PHP  
Nível: intermediário  
Tema: Include, require e organização de arquivos

## Objetivo

Praticar a separação de código em arquivos usando include e require, com validação de entrada e exibição de resultados.

## Conceito

Crie um sistema que receba um número, valide se é positivo, e exiba o resultado em arquivos separados. Use include para reutilizar lógica e organizar o fluxo de execução.

## Desafio

Desenvolva um formulário HTML que envie um número para um arquivo PHP principal. O arquivo principal deve incluir um arquivo de validação e outro de exibição, garantindo que a lógica seja modularizada.

## Pontos principais

- Uso de include/require para modularizar código
- Separação de responsabilidades em arquivos distintos
- Validação de entrada antes da exibição de resultados

## Verificação

- PHP lint OK: exibicao.php
- PHP lint OK: index.php
- PHP lint OK: validacao.php
