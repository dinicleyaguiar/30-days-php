# Dia 08 — Day 08: Formatação de datas

Trilha: PHP  
Nível: iniciante  
Tema: Datas e horários

## Objetivo

Aprender a manipular datas e horários usando funções nativas do PHP

## Conceito

O exercício aborda a formatação de datas usando date_create e date_format. Trabalhamos com diferentes formatos de saída para demonstrar como personalizar a exibição de datas.

## Desafio

Crie um script que receba uma data no formato 'YYYY-MM-DD' e a exiba como 'D de Mês de AAAA' (ex: 5 de outubro de 2023).

## Pontos principais

- Uso de date_create para parsear datas
- Manipulação de objetos DateTime
- Formatos de data personalizados com date_format
