# Dia 04 — Loops for, while e foreach

Trilha: PHP  
Nível: iniciante  
Tema: Loops for, while e foreach

## Objetivo

Praticar loops em PHP com exemplos claros e estruturados

## Conceito

Crie um arquivo PHP que demonstre o uso dos loops for, while e foreach com comentários explicativos. O exercício deve mostrar como cada estrutura funciona em contextos diferentes.

## Desafio

Implemente um script que: 1) Use for para imprimir números de 1 a 10 2) Use while para contar de 10 a 0 3) Use foreach para iterar sobre um array de números e exibir seus valores

## Pontos principais

- Diferença entre loops com condições fixas e variáveis de controle
- Iteração sobre arrays associativos e numerados
- Estrutura de blocos em PHP
