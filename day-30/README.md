# Dia 30 — Projeto Final: Sistema de Quiz com Autenticação

Trilha: PHP  
Nível: avançado  
Tema: Projeto final PHP

## Objetivo

Criar um sistema de quiz com autenticação de usuário, usando sessões, formulários e banco de dados.

## Conceito

Este exercício combina conceitos avançados como autenticação de usuário, manipulação de formulários, armazenamento em banco de dados e validação de dados. O sistema permitirá que usuários criem quizzes, respondam a eles e vejam seus resultados.

## Desafio

Implementar um sistema completo com autenticação, criação de quizzes, resposta de perguntas e exibição de resultados, garantindo segurança e validação de dados.

## Pontos principais

- Autenticação de usuário com sessões
- Manipulação de formulários com validação
- Armazenamento de dados em banco de dados
- Validação de dados com prepared statements
- Exibição dinâmica de resultados
