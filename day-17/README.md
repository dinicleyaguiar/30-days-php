# Dia 17 — Day 17: Configurando Composer e autoloading para classes PHP

Trilha: PHP  
Nível: intermediário  
Tema: Composer e autoloading

## Objetivo

Implementar um sistema de autoloading com Composer para gerenciar classes PHP em um projeto modular.

## Conceito

Crie um projeto com múltiplas classes que utilizem autoloading via Composer. Demonstre como estruturar arquivos, definir namespaces e usar o autoload para evitar include manual.

## Desafio

Desenvolva um sistema de cálculo matemático com classes separadas e autoloading. Implemente métodos para adição, subtração e multiplicação.

## Pontos principais

- Configuração do Composer para autoloading
- Estrutura de diretórios para projetos PHP
- Uso de namespaces e classes em múltiplos arquivos
