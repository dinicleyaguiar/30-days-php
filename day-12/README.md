# Dia 12 — Day 12: Leitura e escrita de arquivos

Trilha: PHP  
Nível: intermediário  
Tema: Leitura e escrita de arquivos

## Objetivo

Praticar operações de leitura e escrita de arquivos em PHP, incluindo manipulação de conteúdo.

## Conceito

Crie um script que leia um arquivo de texto, processe seu conteúdo (ex: converta todas as letras para minúsculas) e escreva o resultado em um novo arquivo. Inclua tratamento de erros para verificar se os arquivos existem.

## Desafio

Implemente a lógica para manter o conteúdo original intacto enquanto cria o arquivo de saída.

## Pontos principais

- Uso de fopen, fread, fwrite e fclose
- Manipulação de strings com strtolower
- Verificação de permissões de arquivo

- PHP lint OK: processa_arquivo.php
