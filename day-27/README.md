# Dia 27 — Sistema de Autenticação com Roles

Trilha: PHP  
Nível: avançado  
Tema: Autenticação e autorização

## Objetivo

Implementar um sistema de login com verificação de credenciais e controle de acesso por roles.

## Conceito

Crie um sistema que valide credenciais contra um arquivo de usuários e restrinja acesso a páginas com base em roles (ex: 'admin' e 'user').

## Desafio

Implemente a lógica de autenticação, armazene sessões e valide permissões de acesso.

## Pontos principais

- Validação de credenciais contra fonte de dados
- Gerenciamento de sessões para autenticação
- Controle de acesso com roles
