# Dia 02 — Day 02: Exercício com operadores aritméticos e lógicos

Trilha: PHP  
Nível: iniciante  
Tema: Operadores aritméticos e lógicos

## Objetivo

Praticar operadores aritméticos e lógicos em PHP com exemplos claros

## Conceito

Este exercício demonstra o uso de operadores aritméticos (+, -, *, /, %) e lógicos (&&, ||, !) em cálculos e condições. Os resultados são exibidos com echo para visualização.

## Desafio

Crie uma versão do script que calcule a média de três números e verifique se é maior que 7 usando operadores lógicos.

## Pontos principais

- Operadores aritméticos para cálculos básicos
- Operadores lógicos para tomada de decisão
- Uso de echo para exibir resultados
