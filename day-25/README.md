# Dia 25 — Day 25: Implementação de arquitetura MVC com separação de responsabilidades

Trilha: PHP  
Nível: avançado  
Tema: Arquitetura MVC

## Objetivo

Criar um exemplo prático de arquitetura MVC para um sistema de tarefas, separando lógica, apresentação e dados.

## Conceito

Este exercício demonstra a divisão em Model, View e Controller. O Model gerencia dados, o Controller processa requisições e a View exibe conteúdo. Não utiliza banco de dados para simplificar a estrutura.

## Desafio

Implementar um sistema que permita adicionar tarefas, exibindo-as em uma lista, com separação clara entre camadas.

## Pontos principais

- Padrão de arquitetura MVC
- Separação de responsabilidades
- Fluxo de requisição em PHP
