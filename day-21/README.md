# Dia 21 — Day 21: Implementação de padrão de projeto com classes abstratas

Trilha: PHP  
Nível: avançado  
Tema: Programação orientada a objetos

## Objetivo

Criar um sistema de gerenciamento de produtos usando classes abstratas e polimorfismo para demonstrar conceitos avançados de orientação a objetos.

## Conceito

O exercício exige a criação de uma hierarquia de classes que represente produtos com diferentes tipos de descontos. Serão implementadas classes abstratas, subclasses e métodos sobrescritos para mostrar como o PHP lida com herança e polimorfismo em cenários reais.

## Desafio

Desenvolva um sistema que permita: 1) Criar produtos comuns e produtos com desconto 2) Calcular preços com regras diferentes 3) Usar classes abstratas para definir contratos

## Pontos principais

- Classes abstratas e métodos abstratos
- Polimorfismo em PHP
- Herança de classes
- Padrões de projeto básicos
