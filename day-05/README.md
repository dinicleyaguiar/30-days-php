# Dia 05 — Manipulação de Arrays

Trilha: PHP  
Nível: iniciante  
Tema: Arrays indexados e associativos

## Objetivo

Praticar a criação e manipulação de arrays indexados e associativos em PHP

## Conceito

Crie dois arrays: um indexado com nomes de alunos e outro associativo com notas. Combine-os em um array final e exiba os resultados usando funções de array.

## Desafio

Implemente a lógica para mesclar os arrays e exibir os dados sem usar loops.

## Pontos principais

- Diferença entre arrays indexados e associativos
- Uso de funções de array para manipulação
- Estrutura de dados para armazenar informações relacionadas
