# Dia 26 — API REST para Lista de Tarefas

Trilha: PHP  
Nível: avançado  
Tema: Construção de API REST

## Objetivo

Criar uma API REST com endpoints para CRUD de tarefas usando PDO e JSON

## Conceito

Implemente uma API que permita listar, criar, atualizar e excluir tarefas. Use HTTP methods (GET, POST, PUT, DELETE) e retorne respostas em formato JSON. Garanta validações básicas e tratamento de erros.

## Desafio

Desenvolva a lógica para cada endpoint sem usar frameworks, mantendo a segurança e a organização do código.

## Pontos principais

- Manipulação de requisições HTTP
- Trabalho com JSON
- Validação de entrada
- Tratamento de erros em APIs
