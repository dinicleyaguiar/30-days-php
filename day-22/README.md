# Dia 22 — Herança e Polimorfismo - Forma Geométrica

Trilha: PHP  
Nível: avançado  
Tema: Herança e polimorfismo

## Objetivo

Implementar uma hierarquia de classes que demonstre herança e polimorfismo com cálculo de área

## Conceito

Crie uma classe abstrata Forma com método calcularArea(). Implemente subclasses Circulo, Retangulo e Quadrado que herdem dessa classe. Mostre como diferentes implementações do mesmo método produzem resultados distintos.

## Desafio

Crie um sistema que calcule a área de diferentes formas usando polimorfismo, incluindo uma forma especial que herde de outra

## Pontos principais

- Herança de classes abstratas
- Sobrescrita de métodos
- Polimorfismo em ação
- Padrões de design básicos
