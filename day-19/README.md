# Dia 19 — Day 19: CRUD com PDO - Lista de Tarefas

Trilha: PHP  
Nível: intermediário  
Tema: CRUD com PDO

## Objetivo

Implementar um sistema de gerenciamento de tarefas com operações CRUD usando PDO

## Conceito

Criaremos um exemplo prático de CRUD (Create, Read, Update, Delete) com PDO. O sistema permitirá adicionar, editar, excluir e marcar tarefas como concluídas. O foco será na manipulação direta do banco de dados sem frameworks.

## Desafio

Implementar todas as operações de CRUD com validações básicas e garantir que o código seja reutilizável.

## Pontos principais

- Uso de PDO para consultas SQL seguras
- Manipulação de dados com prepared statements
- Gerenciamento de estados (concluída/não concluída)
- Arquitetura modular com separação de responsabilidades
